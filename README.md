# Simple Web Application For Targeted Ad Generation
# Purpose: 
This app generates targeted ads personalized for each customer based on their purchase history. 

To run the app, download this repository to your computer, unzip the repository files, open a Python terminal, navigate to the "./TargetedAdsGenerator" directory, and run "streamlit run app.py". 

Note: The app has only been tested to run locally.

# Important: 
The Pandas and Twilio libraries must be installed for this app to run. To use the email and SMS integration features, you must provide your own Gmail SMTP credentials and Twilio API keys.
